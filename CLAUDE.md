# Instructions for AI assistants working in this repository

This is a final project for CSPB 2270 (Data Structures): a
Q-learning gridworld agent written in C++.

## README.md is written by the student only

- `README.md` in the project root is the document the professor grades.
  **The student writes it themselves.**
- Do **not** create, overwrite, rewrite, or "clean up" `README.md`.
- Do not paste generated prose into `README.md`, even if asked to "draft a
  section". Instead, put the draft in a separate file under `notes/` and tell
  the student where it is so they can write their own version.
- Small mechanical fixes to `README.md` (a broken link, a typo the student points
  at) are allowed only when the student asks for that specific change.

## Other Markdown files may be generated

- AI tools may generate other `.md` files (study notes, algorithm lists,
  design sketches, checklists). Put them in `notes/`, not the project root.
- Start every generated `.md` file with this line so it is clearly not
  the student's own writing:

  `> AI-generated study note — not part of the graded write-up.`

## Project context

- Language: C++ (no Python in the deliverable).
- Course requirement: the README must name the data structure implemented,
  explain it briefly, give complexity, and explain how to build/run.
- Planned environment: gridworld starting at 5x5 with a key and a door, then
  larger grids with walls.

## notes/reviewed/ is read-only for AI tools

- When the student has read a generated note, they move it into
  `notes/reviewed/`.
- Do **not** edit, overwrite, rename, move, or delete anything in
  `notes/reviewed/`. Treat those files as frozen.
- If a reviewed note needs a correction or update, write a new file in
  `notes/` (e.g. `RL_ALGORITHMS_v2.md` or `RL_ALGORITHMS_addendum.md`) and tell
  the student, so they can review it and move it in themselves.
